# Council

Ask one question and two AIs work it out. Claude and Gemini each answer on their own with web search, critique each other's answers, defend or concede, revise, then merge into one final answer that lists where they still disagree and how confident they are.

**Open the app:** https://mrbooty42.github.io/council/

## How it works
1. **Opening:** both models answer independently.
2. **Cross-examine:** each one critiques the other's answer.
3. **Revise:** each concedes or defends, then improves its answer. Quick runs this once, Standard twice, Deep three times. It stops early if both fully agree.
4. **Verdict:** one model merges the best of both into a single answer.

Also: PDF, Word, PowerPoint and photo uploads; solo mode (one model, much cheaper); a monthly spend tracker; Download for Word; history backup.

## Privacy
The app is one HTML file that runs in your browser. Your API keys and history are stored only in that browser. Questions go straight from your browser to Anthropic and Google. No other server is involved, and nothing private is stored in this repository.
